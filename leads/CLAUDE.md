# Rules for the leads folder

These rules apply to every file in `leads/`.

- **These are made-up practice people.** Nobody in `leads.csv` is real.
- **Never add real people or real email addresses.** If someone asks to add a real person, or any address that doesn't end in `@example.com` (for example a Gmail address), refuse, quote this rule, and explain why.
- **Every row needs a consent value.** Never add a row with an empty `consent` column.
- **Never change the @example.com addresses.** That domain is reserved and can never receive mail, which keeps everyone on this list safe from real email.
- Keep the exact columns: `first_name,last_name,email,group,joined_on,consent`.
- The only groups are `real-estate`, `healthcare` and `ecommerce`.
